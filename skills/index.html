Agent skills

Skills that teach your coding agent a specific job.

These are the instruction sets I keep for agents like Claude Code, Codex and Cursor. Each one covers a particular kind of work, such as reviewing code, designing a screen or putting a site online, so pick what you’re trying to do, read what the skill is for, and copy a prompt that installs it in one project or across all of them.

89 skills, free to use, with the source on GitHub and the same files the yeknal CLI installs.

npx yeknal@latest setup

Adds a short instruction block to the coding agents it finds on your computer, so they can search this catalog and load a skill only when a task calls for one. Nothing is copied into your skills folders, existing skills stay where they are, and npx yeknal@latest setup --remove takes the instructions out again.

Install all 89 skills

npx yeknal@latest skills --all

Copies every skill into each user-level skills folder it detects. It replaces earlier yeknal- copies, including any edits you made to them, and removes yeknal- skills that have left the catalog. Skills with other names are left alone.

Several skills are adapted from other authors and keep their original licenses, which are credited on each skill’s page.
