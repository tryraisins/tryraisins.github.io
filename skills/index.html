Agent skills

Skills that teach your coding agent a specific job.

These are the instruction sets I keep for agents like Claude Code, Codex and Cursor. Each one covers a particular kind of work, such as reviewing code, designing a screen or putting a site online, so pick what you’re trying to do, read what the skill is for, and copy a prompt that installs it in one project or across all of them.

81 skills, free to use, with the source on GitHub and the same files the yeknal CLI installs.
