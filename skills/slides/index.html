When to use it

  • You need a new .pptx deck built.
  • Slides should be recreated from screenshots or a PDF.
  • Text overflows or fonts change when the deck opens elsewhere.

A practical example

You ask

“Make a ten-slide deck from this project update, with one chart.”

Your agent does

It builds an editable deck with the chart, renders every slide and fixes overflow before handing it over.

What gets installed

The whole folder is copied, so scripts, references and any license notices stay together.
