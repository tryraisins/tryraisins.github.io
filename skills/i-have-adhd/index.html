When to use it

  • You prefer answers that lead with the next action.
  • Long explanations make it hard to keep track.
  • You want progress shown clearly as work moves along.

It only runs when you turn it on by asking for it.

A practical example

You ask

“ADHD mode on. Help me set up the project locally.”

It answers with one clear step at a time, keeps the current state visible and skips long preambles.
