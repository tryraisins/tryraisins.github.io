When to use it

  • You want a focused commit without sweeping in other changes.
  • You need help with a branch, merge or history question.
  • Your working tree has unrelated edits that must survive.

A practical example

You ask

“Commit only the API changes and push them to a new branch.”

Your agent does

It stages just those files, writes a clear commit message, creates the branch and pushes it.
