When to use it

  • A feature spec lives in Notion and needs breaking down.
  • You want tasks created and tracked against the spec.
  • Progress should be visible to the rest of the team.

A practical example

You ask

“Turn the notifications PRD into an implementation plan with tasks.”

Your agent does

It reads the spec, writes a plan and creates linked tasks in Notion for tracking.

What gets installed

The whole folder is copied, so scripts, references and any license notices stay together.
