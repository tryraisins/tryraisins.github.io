When to use it

  • You want to host a site or API on Cloudflare.
  • You are setting up Workers, Pages, KV or R2 for a project.
  • A Cloudflare deployment needs configuring or fixing.

A practical example

You ask

“Deploy this Astro site to Cloudflare Pages with a preview for every branch.”

Your agent does

It configures the project for Pages, deploys it with Wrangler and gives you the preview and production URLs.

What gets installed

The whole folder is copied, so scripts, references and any license notices stay together.
