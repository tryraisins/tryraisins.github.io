# Minimalist UI

> Designs clean editorial interfaces with warm monochrome palettes, strong typographic contrast, flat grids and restrained depth.

Canonical: https://tryraisins.dev/skills/minimalist-ui/
Source revision: 00061b8

Design clean editorial interfaces with warm monochrome palettes, typographic contrast, flat bento grids, and restrained depth. Use when the brief calls for premium utilitarian minimalism.

## When to use

- The brief calls for calm, premium minimalism.
- An interface feels cluttered and needs restraint.
- You want typography to carry the hierarchy.

## Example

Ask: Redesign the settings page in a warm, minimal editorial style.

Outcome: It reduces the palette, strengthens the type hierarchy and groups settings with space instead of boxes.
