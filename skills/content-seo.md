# Content and SEO

> Guides useful content and search visibility together, from keyword patterns and page briefs to metadata, structured data, sitemaps, local search, earned links and AI citations.

Canonical: https://tryraisins.dev/skills/content-seo/
Source revision: 95a39b5

Evidence-led search visibility: target queries, update-or-create decisions, metadata, structured data, crawlability, sitemaps, canonicalization, local search, earned links, AI answers (AEO/GEO), and measured citations. Use for SEO, AEO or GEO strategy.

## When to use

- You are choosing which queries to target and which pages should exist.
- You are planning or rewriting pages and want them to be found.
- Metadata, canonical tags, crawlability or structured data need an audit.
- A local business is invisible in the map pack, or links and coverage need a plan.
- Traffic moved and you need to separate a ranking loss from a click-through loss.
- You want a site to be readable by search engines and AI search alike.

## Example

Ask: Choose the queries worth targeting and tell me whether to update an existing page or create a new one.

Outcome: It reads the live results, checks existing query and page data, and returns a decision, a brief and the evidence behind it.
