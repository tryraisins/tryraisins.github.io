When to use it

  • You are working on a Blazor, Razor Pages, MVC or Web API project.
  • Middleware, dependency injection or configuration needs to follow current guidance.
  • You are planning an ASP.NET Core upgrade.

A practical example

You ask

“Add a Minimal API endpoint for orders with validation and proper authorization.”

Your agent does

It follows the project’s existing conventions, adds the endpoint with validation and policy-based authorization, and notes how to test it.
