# High-end visual design

> Creates art-directed, showcase-level web interfaces with a product-specific visual idea, expressive type, deliberate composition and considered motion.

Canonical: https://tryraisins.dev/skills/high-end-visual-design/
Source revision: fc6b3b7

Create premium, art-directed web interfaces with a product-specific visual thesis, expressive type, deliberate composition, material, imagery, and motion. Use only for showcase-level or agency-style briefs.

## When to use

- The brief explicitly asks for agency, editorial or experimental quality.
- A launch or showcase page needs a strong visual idea.
- Ordinary product styling isn’t enough for this piece.

## When not to use

For everyday product UI, use Frontend design instead.

## Example

Ask: Art-direct the launch page for our camera app as if it were a magazine feature.

Outcome: It develops a visual thesis from the product, then builds a page with editorial type, imagery and restrained motion.
