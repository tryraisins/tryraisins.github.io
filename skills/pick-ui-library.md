# Pick a UI library

> Recommends the right library or inspectable source registry for a frontend need from a curated list, from accessible primitives to charts, toasts and drag and drop.

Canonical: https://tryraisins.dev/skills/pick-ui-library/
Source revision: 95a39b5

Pick a frontend library or inspectable source registry from a curated list of accessible primitives, React components, motion, charts, virtualization, drag and drop, toasts, and styling. Only runs when explicitly invoked.

## When to use

- You need a component library and don’t want to guess.
- You are choosing between options for charts, menus or virtualised lists.
- You want something accessible and actively maintained.

## When not to use

It only runs when you ask for it by name.

## Example

Ask: Which library should I use for an accessible command menu in React?

Outcome: It compares a few candidates from its list and recommends one with reasons and install notes.
