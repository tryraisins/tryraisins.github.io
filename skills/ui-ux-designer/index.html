When to use it

  • You are shaping how a product is organised and navigated.
  • A flow is confusing and needs rethinking.
  • You need a UI specification someone can build from.

A practical example

“Rethink how people find and manage saved reports.”

Your agent does

It maps the current flow, proposes a clearer structure and specifies the screens and interactions.
