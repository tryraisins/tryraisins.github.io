When to use it

  • You need current guidance on an OpenAI API or model.
  • You are migrating to a newer model.
  • An answer needs citing to the official docs.

A practical example

You ask

“Which OpenAI model should we use for structured extraction now, and what changes?”

Your agent does

It checks the current documentation, recommends a model and lists the changes with citations.
