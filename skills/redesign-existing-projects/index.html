When to use it

  • A product works but looks dated or generic.
  • Responsive layouts are broken and need repairing.
  • You want UX improvements without rewriting the app.

A practical example

You ask

“Give the admin dashboard a visual refresh without changing how anything works.”

Your agent does

It inventories every route and state first, then restyles them while keeping each feature behaving the same.
