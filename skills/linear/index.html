When to use it

  • You want tickets created from a plan or a bug report.
  • Issue status needs updating as work progresses.
  • You want a summary of what’s in a project.

A practical example

You ask

“Create Linear issues for each task in this plan and add them to the current cycle.”

Your agent does

It creates one issue per task with a clear description and adds them to the cycle.
