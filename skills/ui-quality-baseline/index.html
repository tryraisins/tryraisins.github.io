When to use it

  • You want every UI change held to the same standard.
  • Layouts break at small widths or with large text.
  • Loading, empty and error states keep getting forgotten.

A practical example

You ask

“Check the new onboarding screens against the UI baseline.”

Your agent does

It checks spacing, contrast, focus, responsive containment and states, then fixes what fails.
