When to use it

  • You are adding an AI feature to a product.
  • Users need to see where an answer came from or how sure it is.
  • An agent can take actions that need approval or undo.

A practical example

You ask

“Design how our assistant proposes calendar changes before it makes them.”

Your agent does

It designs a review step with clear sources, editable proposals, approval and a way to undo.
