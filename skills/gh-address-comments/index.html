When to use it

  • A pull request has review comments waiting.
  • You want each comment addressed or answered in turn.
  • You use the gh CLI and want the agent to read the PR directly.

A practical example

You ask

“Address the review comments on my PR.”

Your agent does

It checks gh is signed in, reads each comment, makes the changes and summarises what it did for each one.
