When to use it

  • You are building authentication, authorization or an API that handles user data.
  • A project needs a broad security pass before launch.
  • You want secure defaults for headers, secrets, rate limits and logging.

A practical example

You ask

“Harden the API before we launch: auth, rate limiting, headers and how secrets are handled.”

Your agent does

It reviews each area against concrete risks, fixes what it can and lists anything that needs a decision from you.
