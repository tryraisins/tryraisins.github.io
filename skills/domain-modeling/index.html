When to use it

  • People use different words for the same thing, or one word for two things.
  • System boundaries are unclear before a larger change.
  • You want a GLOSSARY.md or an ADR written down.

A practical example

You ask

“We keep mixing up accounts, workspaces and organisations. Sort out the terms.”

Your agent does

It maps how each term is used in code and conversation, proposes definitions and records them in a glossary.

What gets installed
