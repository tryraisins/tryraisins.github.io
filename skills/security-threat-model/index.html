When to use it

  • You are launching something that handles sensitive data.
  • You want to understand how the system could be abused.
  • A security review needs a threat model first.

It only runs when you ask for a threat model.

A practical example

You ask

“Threat model the new public API.”

Your agent does

It maps assets and trust boundaries from the code, lists likely abuse paths and recommends mitigations by priority.
